# 🔢 Armstrong Number Checker in C++

A beginner-friendly C++ program that checks whether an entered number is an Armstrong number.

## ✨ How It Works

The program counts the digits in a number, raises each digit to that count, and adds the results.

For example:

- `153` is an Armstrong number because `1³ + 5³ + 3³ = 153`.
- `123` is not an Armstrong number because `1³ + 2³ + 3³ = 36`.

## 🧠 Concepts Used

- User input and output
- `while` loops
- Arithmetic operators
- `if-else` statements
- The `pow()` function from `<cmath>`
